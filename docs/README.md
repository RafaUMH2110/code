## Dónde va cada documento

| Tipo | Dónde |
|---|---|
| Manual, README o guía de **una app** | Junto a su app (`telemetria/home/telehome-servicio/README.md`, `scripts/telemet-collector-info/MANUAL.md`…). Así se actualiza con su código |
| Guía o documento **general** (flujo de trabajo, traspasos, procedimientos) | Aquí, en `docs/` |

Reglas: nombres de fichero en minúsculas y con guiones, en Markdown, con la fecha de la última revisión cuando el contenido pueda quedarse viejo.
