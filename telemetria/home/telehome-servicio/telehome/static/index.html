    Entrar

    Escribe tu contraseña. La de usuario permite encender y apagar; la de administrador, además, configurarlo todo. Sin ninguna, la interfaz solo muestra las lecturas.

    La sesión dura 12 horas y se cierra al cerrar la pestaña. Las contraseñas se ponen con telehome admin-password y telehome user-password.

    Ajustes y enchufes

    Solo un administrador puede cambiar la configuración. Si has entrado como usuario, puedes manejar los enchufes pero no tocar los ajustes.

    Enchufes configurados

    Añadir enchufe

    En modo local el programa habla con el enchufe en tu red (necesita su Local Key). En modo nube lo lee a través de la API de Tuya, desde cualquier sitio.
    Avanzado: mapa de datos y escalas

    Credenciales del proyecto de Tuya

    Para leer y controlar los enchufes sin estar en su red (por ejemplo, desde un servidor). Necesita un proyecto en iot.tuya.com con tu cuenta de Smart Life o Tuya Smart enlazada e IoT Core autorizado; copia aquí su Access ID y Access Secret. Para encender y apagar, cada enchufe debe tener Device Permission = Controllable.

    Buscar en la red local

    Encuentra enchufes Tuya por difusión UDP (tarda unos 12 s) y rellena IP, Device ID y versión. La Local Key se obtiene con python -m tinytuya wizard.

    Importar devices.json (TinyTuya)

    Añade de una vez los enchufes del fichero que genera el asistente de TinyTuya.

    Lectura e histórico

    Contraseña del servicio

    Es la que hay que escribir para abrir el servicio.

    La contraseña actual no se puede mostrar: se guarda cifrada en un solo sentido (PBKDF2), así que ni el servicio la conoce. La del modo Administrador se cambia con telehome admin-password.

    Contraseña de usuario de confianza

    Quien la tenga puede manejar los enchufes (encender, apagar, regular), pero no cambiar la configuración ni las contraseñas.

    Tampoco se puede mostrar la actual: se guarda cifrada en un solo sentido. Sin contraseña de administrador puesta, esta por sí sola deja la configuración accesible solo desde la línea de órdenes.

    Llamadas a la API de Tuya

    Cuántas llamadas ha hecho el servicio a la nube de Tuya (lectura de estado, órdenes y renovación del token). El uso oficial lo muestra iot.tuya.com en Cloud → Usage (API Statistics); compáralo con estas cifras. Los créditos de Cobuilder (IA) no cuentan estas llamadas.

    Programaciones

    Encienden, apagan o regulan un enchufe a una hora, al amanecer o al anochecer. Las evalúa el servicio, así que funcionan aunque no tengas la app abierta.

    Nueva programación

    Días que se repite

    Sin ningún día marcado, la programación se ejecuta una sola vez: la próxima vez que llegue ese momento, y después queda desactivada.

    Lugar

    Para calcular el amanecer y el anochecer.

    Exportar la configuración

    Guarda en un fichero los enchufes (con su Local Key), el Access ID y el Access Secret de tuya.com y el resto de ajustes, para que otra persona los cargue y no tenga que configurar nada. No incluye la contraseña de este servicio.

    El fichero contiene credenciales y claves de tus dispositivos: compártelo solo con quien debas y bórralo cuando ya no haga falta.

    Importar una configuración

    Carga un fichero creado con «Exportar configuración». La contraseña de este servicio no se modifica.
